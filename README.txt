
Матрикс Extended — Полная версия
--------------------------------

Что внутри:
- index.html — интерфейс (чат + кнопки режимов)
- style.css — оформление (киберпанк стиль)
- script.js — логика общения (чат, режимы, голос, заглушки картинок и музыки)
- config.js — твои ключи (Gemini + ElevenLabs)
- README.txt — это описание

Как запускать:
1. Распакуй архив в папку.
2. В config.js ключи уже прописаны.
3. Открой index.html в Chrome / Firefox / Kiwi (Android).
4. Пиши или говори — Матрикс ответит и озвучит.
